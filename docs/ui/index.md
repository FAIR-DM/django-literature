# Web interface

`literature.ui` is an optional app that gives a project a complete web interface for its
references: a catalogue, a page for each reference and contributor, and pages to add, edit, delete
and import references. It also gives your own forms and pages a reference picker and a display
component. Start with [Installing the web interface](installation.md).
