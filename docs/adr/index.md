# Decision records

Each record states one decision, why it was taken, and what it rules out. They are written when the
decision is made and left in place afterwards — a record that has been overtaken is marked
superseded and kept, because the reasoning that led to it is part of how the package arrived where
it is.

Read one when you want to know why something works the way it does rather than how to use it. The
rest of this documentation covers the how.
