# How to import a bibliography file

Turn a BibTeX or RIS file exported from another tool into references in the catalogue, from the
front end. To import a file from code instead, see
[How to import a bibliography file in code](import-a-bibliography-file-in-code.md).

## Before you start

You need the `literature.add_item` permission. A visitor who is not signed in is sent to sign in.

## Steps

1. On the table catalogue, choose **Import** at the end of the toolbar.
2. Choose the file's format, attach the file, and submit. The page does not work the format out
   from the file, so choose the one that matches it.
3. Read the preview. It lists every entry in the file with what would happen to it: created,
   skipped or failed, with a reason for each skip and failure. Nothing has been imported yet.
4. To see only one outcome, such as the failures, choose its button above the table. **All** shows
   every entry again.
5. Choose **Confirm import**. To start again with a different file, choose **Restart import**
   instead.

To import in one step without a preview, tick "Skip the preview and import immediately" at
step 2.

## The result

You are back on the catalogue, with a message saying how many entries were created, skipped and
failed. Importing the same file again creates its references again.

Every page and control of the import is described in [Import pages](../reference/import-pages.md).
